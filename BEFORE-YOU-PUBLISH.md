# Publishing checklist

- [ ] Review screenshots for hostnames, usernames, private/public IPs and SSH authentication metadata; redact anything you do not want publicly accessible.
- [ ] Verify there are no passwords, private keys, secrets or unreviewed full system logs in your upload.
- [ ] Confirm `README.md` is at the repository root (no extra nested project folder).
- [ ] Upload the **contents** of this folder to the GitHub repository through **Add file → Upload files**.
- [ ] Commit with message: `Add six documented Ubuntu administration labs and evidence`.
- [ ] Open a few README links to check that documentation and screenshots display correctly.

All six labs reflect a personal training environment, not production support work.
